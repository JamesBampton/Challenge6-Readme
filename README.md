## Description
Build a Python script that prompts the user for details about their GitHub project using `PyInquirer`. The application generates a 'README.md@ file using GitHub markdown (md)

---

## Install
Create/run a virtual environment - Set Up a Virtual Environment - 
1. Navigate to your project folder: mkdir my_python_project - cd my_python_project - 
2. Create a virtual environment: python -m venv venv - 
3. Activate the virtual environment - venv\Scripts\activate - 
4. Place file with new folder (mainCp.py, my_module.py, myIntroduction.py, requirements.txt)- 
5. run pip install -r requirements.txt (to install required modules)

---

## Usage
run python mainCp.py and enter all required prompts
